# Self-Hosted LLM "Infra Copilot" - Tasks

## What to Build
Slack bot that answers DevOps questions using local Llama model + kubectl/Prometheus queries

## Tasks

### 1. Core Files
- [ ] `Dockerfile` - Multi-arch image with Ollama + Llama-2-7B
- [ ] `main.py` - FastAPI app with `/chat` endpoint 
- [ ] `llm_service.py` - Ollama integration wrapper
- [ ] `k8s_client.py` - kubectl commands via Python k8s client
- [ ] `prometheus_client.py` - Query Prometheus metrics
- [ ] `vector_store.py` - Qdrant integration for FAQ/runbooks
- [ ] `slack_bot.py` - Slack slash command handler
- [ ] `requirements.txt` - Python dependencies

### 2. Kubernetes Manifests
- [ ] `deployment.yaml` - Main app deployment
- [ ] `service.yaml` - Service load balancer
- [ ] `rbac.yaml` - ServiceAccount + RBAC for kubectl access
- [ ] `hpa.yaml` - HPA with custom requests/sec metric
- [ ] `configmap.yaml` - Configuration (Slack tokens, etc.)
- [ ] `qdrant.yaml` - Qdrant vector database

### 3. Configuration
- [ ] `.env.example` - Placeholder for secrets
- [ ] `config.py` - App configuration management
- [ ] `docker-compose.yml` - Local development setup

### 4. Setup Scripts
- [ ] `setup.sh` - Initialize FAQ data in Qdrant
- [ ] `build.sh` - Multi-arch Docker build script

## Placeholders Needed
- `SLACK_BOT_TOKEN`
- `SLACK_SIGNING_SECRET` 
- `PROMETHEUS_URL`
- `QDRANT_URL`
- `KUBERNETES_NAMESPACE`
